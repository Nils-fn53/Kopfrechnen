# Kopfrechnen
 
A small web app for practicing mental arithmetic, right in the browser or as a shortcut on the iPhone home screen. ("Kopfrechnen" is German for mental arithmetic.)
 
## What is this about?
 
I was using [Zetamac](https://arithmetic.zetamac.com) to practice mental math and really liked the idea. But I didn't like the design, and I didn't like the constant time pressure. So I built my own version that works exactly the way I want it for practicing.
 
**My goal:** A calm, uncluttered practice tool where I decide whether to play with or without a timer.
 
## Features
 
- A problem is shown as soon as the app opens, just type in the answer
- Choose **untimed** or **timed** mode (30 s to 5 min)
- Select operations individually: +, −, ×, ÷, percentages and fractions
- Freely adjustable number ranges
- Statistics: problems solved, average time, breakdown by type of problem
- Light and dark mode, optimized for smartphones
Settings and statistics are stored locally in your browser only. Your answers and statistics are never sent anywhere. The page uses [Umami](https://umami.is) for anonymous, cookie-free visitor statistics (e.g. page views).
 
## Usage
 
Open the page in your browser. On iPhone in Safari: Share → "Add to Home Screen".
